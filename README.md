# 🗳️ School Election Management System

A modern, responsive, and user-friendly web application designed to conduct school elections digitally. This system allows school administrators to create election positions, add candidates, collect votes efficiently, and export final results to Excel.

## 🚀 How It Works

1. Enter the school name.
2. Create election positions (School Captain, Vice Captain, etc.).
3. Add candidates for each position.
4. Set an admin password.
5. Start the election.
6. Students vote for candidates position by position.
7. Continue voting for all students using the "Start Next Vote" option.
8. Finish the election using the admin password.
9. View and download the final results in Excel format.
